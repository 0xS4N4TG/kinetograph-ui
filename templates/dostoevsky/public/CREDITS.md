# Dostoevsky reel: image sources

Files in `raw/` are what was fetched. Files in this folder are the crops and cut-outs. Cut-outs were made with rembg (isnet-general-use) or hand-built masks (see notes), and checked on mid-grey. Original pixel colours are kept. Every file here is public domain by age or an open licence; the reason is on each entry. Wikimedia Commons refuses curl, so Commons files came from the Internet Archive Wayback Machine copy or, where that had none, from a stitched browser capture (marked "browser capture"). Nothing here carries a watermark or caption.

**Slots not supplied:** S1, S2, S3 (period newspaper sheets) were not found in time. S4 is covered by x1/x1b/x1d.
